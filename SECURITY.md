# Security policy

## Supported version

Security fixes are applied to the latest revision of the default branch.

## Reporting a vulnerability

Please report vulnerabilities privately through this repository's GitHub
Security Advisory reporting flow. Do not open a public issue for a suspected
credential exposure, privacy leak, prompt-injection weakness, access-control
bypass, or unsafe external action.

Include a concise description, affected file or behavior, reproduction steps
that do not contain real personal data, and the expected impact. Do not attach
real CVs, credentials, cookies, tokens, session data, or private runtime output.

If private vulnerability reporting is not enabled, contact the repository owner
through a private channel shown on their GitHub profile and ask them to enable
it before sharing sensitive details.

## Safety boundaries

Scout is intended only for public-source job research. A report is security
relevant if Scout can be induced to reveal private candidate data, trust webpage
instructions, use a personal browser session, bypass an access restriction,
submit a form, sign in, upload a file, or communicate externally.
